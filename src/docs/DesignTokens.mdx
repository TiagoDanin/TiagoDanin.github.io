# Design tokens

The values below are the live ones. They are read from the same
`src/app/globals.css` the site loads, so a swatch that looks wrong here is
wrong in production too.

Tailwind maps each token to a utility: `--primary` is `bg-primary` and
`text-primary`. Use the utility, never a raw hex or a stock Tailwind color.
`bg-blue-600` hardcoded outside the theme is a documented ban in `DESIGN.md`.

      </div>
    </div>
  ))}
</div>

**These four never touch text, a button, or a card fill.** They exist as
`blur-3xl` orbs at 20 to 30 percent opacity, positioned at the corners of a
section, marked `aria-hidden`. That diffuse wash is the site's signature; the
same colors used as a flat background would read as a template.

## Type scale

Hierarchy comes from weight before size, which keeps density workable on a
phone. One system stack, no web font, no loading cost.

## Elevation

Cards rest at `shadow-sm` and lift on hover, but only when they lead somewhere.

<div className="grid grid-cols-1 sm:grid-cols-3 gap-4 my-6 not-prose">
  {[
    ['shadow-sm', 'Resting state'],
    ['shadow-md', 'Hover on a linked card'],
    ['shadow-lg', 'Hover on a feature card'],
  ].map(([cls, use]) => (
    <div key={cls} className={`rounded-xl border bg-card p-6 ${cls}`}>
      <code className="text-xs font-semibold">{cls}</code>
      <p className="text-xs text-muted-foreground mt-1">{use}</p>
    </div>
  ))}
</div>

A card lifts with shadow, never with `translateY` or `scale`. Scaling on hover
is allowed on badges and icon links, where the movement is small enough to read
as feedback rather than as the layout shifting.

**Affordance has to be honest.** `cursor-pointer` and a hover lift mean the
thing is clickable. A card with no destination stays flat and static; a
pointer cursor over dead space is worse than no affordance at all.

## Radius and spacing

`--radius` is `0.5rem`. Cards use `rounded-xl` (12px) or `rounded-2xl` (16px),
buttons `rounded-md` (8px), badges and avatars `rounded-full`.

Card padding is `p-6`. Sections breathe at `py-16` to `py-24`, alternating
white against `bg-secondary/30` so the page has rhythm rather than one
uninterrupted column.
