Emoji Memory Jetpack collects no personal data. It asks for no permissions, has no internet access and saves nothing on the phone. The app is no longer on Google Play; this page is for the phones where it is still installed.

I, Tiago Danin, am the developer. Write to TiagoDanin@outlook.com about anything on this page.

### What the app uses

The game reads the phone's motion sensor to tilt the cards and move their shine. Those readings stay in memory while the game is open and are never stored or sent.

There are no analytics, no crash reporting, no ads and no third-party SDK that collects data. The source code is public on GitHub, at TiagoDanin/Emoji-Memory-Jetpack, so anyone can check this.

### Your rights

Since I hold no data about you, there is nothing to access, correct or delete. The LGPD (Lei 13.709/2018) still gives you the right to ask, and I answer at the address above.

### Children

The game is not directed at children, and it collects nothing from anyone, children included.
